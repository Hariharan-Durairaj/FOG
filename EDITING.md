# Editing SASES FOG

All content in the app comes from the **FOG** folder in OneDrive. Change the folder and the app updates within about 15 minutes. Phones receive the changes the next time the app is opened with an internet connection.

## How folders become pages

| In OneDrive | In the app |
|---|---|
| A folder inside **FOG** | A tile on the home screen |
| A folder inside that folder | An entry in that section's list |
| A Word document (`.docx`) | A page with the document's content |
| A folder with only one Word document and no sub-folders | Tapping its tile opens the document straight away |
| An image named `cover.jpg` or `cover.png` | The picture on that section's home tile and page banner |
| Any other image (`.jpg`, `.png`) in a folder | Shown below the content of that folder |

On the home screen, sections with more sub-folders get larger tiles: 6 or more sub-folders gives a wide tile and 12 or more a large tile. Inside a section, topics are shown as a list, with a filter box when there are 10 or more.

## Names and order

- The folder or file name is the title shown in the app, so name them as you want them to appear, for example `Flood safety.docx`.
- To set the order, start the name with a number: `01 Safety`, `02 Storm response`. The number is not shown in the app.
- Folder and file names cannot contain `/` or `:`. Use the look-alike characters `∕` and `꞉` instead (copy them from this guide or from an existing folder name) and the app shows a normal `/` or `:`, for example `Anaphylaxis ∕ Allergic Reactions` or `Awareness꞉ Buses and Coaches`.
- Anything starting with `_` is not published. Use this for drafts, for example a folder named `_Drafts`.

## Writing documents

Write in Word as normal. The app keeps:

- Headings (use Word's **Heading 1** and **Heading 2** styles). A document with three or more Heading 1 sections gets a contents list at the top.
- Bold, italic, underline and strikethrough
- Text colour and highlight colour
- Bulleted and numbered lists
- Tables
- Pictures inserted into the document
- Links

Fonts, font sizes and page layout are adjusted to suit phone screens.

## Images

- Use JPG or PNG. iPhone photos in HEIC format must be converted first.
- Large photos are resized automatically, so there is no need to shrink them.
- A good tile picture is landscape, with the main subject in the middle.

## Checking your changes

Changes appear on the website within about 15 minutes. To see a change on a phone, close and reopen the app while online. A message confirms when new information has been downloaded.
